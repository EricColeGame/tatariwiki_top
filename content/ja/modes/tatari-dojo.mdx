ほとんどのプレイヤーは、自分が準備できるずっと前にタタリ道場と出会う。そこは呪われた修行場であり、すべての教えは戦いとして訪れ、すべての戦いは教訓を残していく — だからこそ重要なのだ。ここを飛ばせば、後で壁にぶつかる。きちんと学べば、残りのゲームが読み解けるようになる。

本ガイドではタタリ道場をモードごとに解説していく。各試練が実際に何を試すのか、難易度ティアがどう上がっていくのか、どの報酬に時間をかける価値があるのか、そして登っていくプレイヤーと足踏みするプレイヤーを分けるルーティンについて。

## タタリ道場とは実際何なのか

その名は*tatari*（祟り）に由来する。これは場所、物、あるいは人に取り憑き、きちんと鎮められるまで離れないという日本の呪いの概念だ。タタリ道場はその概念を修行場へと変える — 呪いが一度きりのストーリーイベントではなく、繰り返し挑める試練として仕組まれた道場だ。中に入り、前回自分を打ち負かした相手に立ち向かい、前より少しだけマシな答えを持って出てくる。

試練は繰り返し可能なので、このモードはチェックポイントではなくスキルの実験室として機能する。中身に一度しか見られないコンテンツはない。すべてに再入場し、調整し直し、再挑戦できる。つまり失敗のコストは、費やした時間以外にはほとんどない。

名前の背景にある伝承を知りたいなら、[日本語の信仰における祟り神のWikipedia概要](https://en.wikipedia.org/wiki/Tatarigami)は、この伝統において呪いがなぜ単に破壊するものではなく、鎮めるものとして扱われるのかを理解するための確かな出発点になる。

| 要素 | 実際の意味 |
|---|---|
| 目的 | ストーリー進行ではなく、繰り返し可能なスキル訓練 |
| 構成 | 明確な勝利条件を持つ個別の試練 |
| 失敗コスト | 低い — リセットして再入場するだけ |
| 難易度 | 段階制で、ローテーションする修飾子付き |
| 最適な用途 | 基礎：間合い、タイミング、リソース管理 |
| 不向きな用途 | ストーリー限定ドロップの周回 |

タタリ道場がこれほど重要なのは、ゲーム後半のほぼすべてのより難しい挑戦が、そこで教わる基礎をすでに身につけていることを前提としているからだ。間合い。予備動作の読み。*攻撃しない*べき瞬間の見極め。こうした習慣は練習するのは退屈で、飛ばすのは高くつく。そして道場は、それらを練習することが宿題ではなく遊びのように感じられるよう設計されている。

## タタリ道場の全モード

モードの実装によって名称は異なるが、根底にあるアーキタイプは驚くほど一貫している。自分がどのアーキタイプに踏み込もうとしているのかを見極めれば、最初の敵が動く前に正しい心構えを選べる。

| モード | 試されるもの | 典型的な所要時間 | 最適な用途 |
|---|---|---|---|
| 無限ウェーブ | 持久力、リソース管理、ターゲット優先度 | 長い | 安定性の構築 |
| タイムアタック | ルート取り、バーストの窓、判断速度 | 短い | 操作の研鑽 |
| 名付き呪い連戦 | パターンの記憶、プレッシャー下での持久 | 中程度 | ストーリーボスの準備 |
| 鏡合わせの稽古 | 自分のビルドのコピーを相手にした基礎 | 短い | 悪い癖の矯正 |
| 協力儀式 | コミュニケーション、役割の規律、共有ライフ | 中程度 | グループプレイ |
| 封印されたデイリー試練 | ローテーションする修飾子への適応 | 短い | 日々の練習 |

**無限ウェーブ**は持久力テストだ。ウェーブはどんどん難しくなる一方なので、測られているのは生のダメージ量ではなく自制心 — 限られたリソースをいつ使い、いつ温存するかの見極めだ。

**タイムアタック**はプレッシャーを反転させる。生き残るのではなく最適化するのであり、良い走りと最高の走りの差は、たいてい最初の数秒で下されるルート判断にある。

**鏡合わせの稽古**はタタリ道場で最も過小評価されているモードだ。自分の構成のコピーと戦うと、自分が杖として頼っている習慣がそのまま露呈する。相手も同じ杖を持っているからだ。

## 難易度ティアと、それが求めるもの

多くのタタリ道場の実装は、おおよそ5つのティアを階段状に上る。名前は変わっても形は変わらない。各段階は単に数値を膨らませるのではなく、セーフティネットを取り除いていく。

| ティア | 変わること | つまずきポイント |
|---|---|---|
| 入門 | 遅い予備動作、寛容な猶予 | ほぼなし — チュートリアルである |
| 熟練 | ローテーションする修飾子が登場 | 修飾子を無視して闇雲に戦う |
| 古参 | リソース不足、長期戦 | 戦闘中に回復が尽きる |
| 達人 | 厳しい猶予、厳しい硬直 | 安全な隙での欲張りなダメージ |
| 呪い | すべてが同時に、セーフティネットなし | スキルではなくティルト |

熟練から古参への跳躍で、多くのプレイヤーが初めて行き詰まりを感じる。そしてそれはほとんどダメージの問題ではない。リソース経済の問題だ。回復が乏しいと、受けた一撃の一つひとつが後で支払う借金になる。下位ティアで気軽に被打ち合いを覚えたプレイヤーは、突然その計算が合わなくなる。

達人と呪いのティアでは、パターン知識が任意ではなくなる。コミュニティの報告は一貫して、これらのティアを反応ではなく記憶＋実行として描写している。戦いをリアルタイムで解読するのではなく、一つ下のティアですでに学んでおくべきなのだ。

## 報酬、進行、そして追う価値のあるもの

タタリ道場の報酬構造は通常、最も価値のあるアンロックが最も難しいクリアではなく、最も早いクリアから得られるように階層化されている。これは意図的だ。新規プレイヤーを引き込みつつ、より高みを目指すベテランを罰しない。

| 報酬の種類 | 入手元 | 優先度 |
|---|---|---|
| 練習用通貨 | クリアした試練全般 | 序盤は高い |
| 技法のアンロック | 各ティアの初回クリア | 高い |
| 週間キャッシュ | 封印された試練 | 中程度 |
| 外見用のお守り | マイルストーンクリア | 低い |
| リーダーボード順位 | タイム制と無限モード | 任意 |

よくある間違いは、タタリ道場を周回場所として扱うことだ。効率的な場所ではない。そこで生み出される価値はスキルであり、スキルは複利で効く。達人ティアのパターンを1時間かけて学んだプレイヤーは、同じ1時間をわずかな強化のために通貨稼ぎに費やしたプレイヤーよりも、ストーリーコンテンツを速くクリアする。

時間が足りないなら、毎回必ず外見より技法のアンロックを優先しよう。新しい道具は遊び方を変える。新しい見た目は変えない。

## 続くタタリ道場ルーティンの作り方

トレーニングモードの上達は、長時間の一気稽古ではなく構造から生まれる。短く、集中した、繰り返しの訪問が、ほぼ常に一度の長い周回に勝る。

### 登る前にウォームアップ

最初の数分は、すでにクリアできるティアに費やす。目的は挑戦ではなく調整 — より難しいものを乗り越えるのに使う前に、タイミングを取り戻すことだ。

### セッションごとに目標を一つだけ

「古参ティアに到達したい」は目標だ。「上手くなりたい」は気分だ。測定可能な単一のターゲットを選び、セッションの他のすべてをそれに奉仕させよう。

### ただ繰り返すのではなく、振り返る

敗北の後、再入場する前に原因を声に出して名指しする。名指しできないなら、それは練習ではなくサイコロを振っているだけだ。タタリ道場で頭打ちになるほとんどのプレイヤーは、失敗を診断しないまま試行を繰り返している。

| 日 | フォーカス | セッションの長さ |
|---|---|---|
| 1日目 | ウォームアップ＋ティア挑戦1回 | 短い |
| 2日目 | 鏡合わせの稽古のみ | 短い |
| 3日目 | タイムアタック | 中程度 |
| 4日目 | 休養、または軽めの無限ウェーブ | 任意 |
| 5日目 | 最も難しいティアへの挑戦 | 長い |
| 6日目 | 一つの弱点に絞ったドリル | 中程度 |
| 7日目 | オフ | — |

### 進歩を止める失敗

| 失敗 | なぜ有害か | 対処 |
|---|---|---|
| 最も難しいティアから始める | スキルではなくフラストレーションが積み上がる | まず一つ下のティアをきれいにクリアする |
| 修飾子を無視する | 敵ではなくルールと戦うことになる | 入る前に修飾子を読む |
| 敗北を振り返らない | 同じ死が繰り返される | 各失敗の原因を記録する |
| ティルト状態でプレイする | 判断の質が崩壊する | 雑な敗北が2回続いたら止める |
| 外見を追いかける | 時間だけ消費し、スキルは変わらない | まず技法をアンロックする |
| 上位ビルドを盲目的にコピーする | 相手のタイミングは自分のタイミングではない | ビルドを自分の手に合わせる |

## よくある質問

**ゲームをクリアするためにタタリ道場をクリアする必要はありますか？**

ほとんどの実装では、いいえ — メインルートを塞ぐのではなく、それと並んで存在する。とはいえ、プレイヤーの経験は、完全に飛ばすと後のコンテンツが明らかに難しくなると強く示唆している。このモードこそ基礎が作られる場所だからだ。

**フルクリアにはどれくらいかかりますか？**

ティアによって、またすでにどれだけパターンを知っているかによって大きく異なる。コミュニティの報告では、下位ティアは数セッションから、最上位は数週間の断続的な練習まで幅がある。目にした単一の数字は事例として扱うべきだ。

**タタリ道場はソロで練習できますか？**

はい。ほとんどのモードはソロ向けに設計されており、協力オプションは通常、要件ではなく追加要素だ。もしグループを組むなら、開始前に役割を決めておこう — 共有ライフでは、曖昧な役割は高くつく。

**同じティアで失敗し続ける場合はどうすればいいですか？**

一つ下のティアに落として、大きなダメージを受けずに2回連続でクリアする。できなければ、問題は特定の癖であり、ティアではない。できれば、問題はたいてい忍耐 — 戦いがまだ与えていない隙を焦って突いているのだ。

タタリ道場は、ゲームにおいて最も華やかでない資質に報いる。反復、自分のミスに対する正直さ、そしてあえて下手であることを受け入れる意志だ。セッションを積み重ねれば、呪いは呪いではなくなる。
