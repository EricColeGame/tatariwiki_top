ほとんどのプレイヤーは最初のタタリ・ホードのランを同じように失敗する。射撃場のように扱ってしまい、包囲戦として扱わないのだ。このモードは欲張りを罰し、忍耐に報い、序盤のあらゆるミスを、数ウェーブ後に支払期限が来る借金へと静かに変える。タタリ・ホードのランで深部まで到達したいなら、そのリズムを理解する必要がある — プレッシャーがどう積み上がり、どこで難易度が跳ね上がり、アリーナが中立でなくなったときにどの役割が実際にスクワッドを立たせ続けるのかを。

このガイドでは、モードの構造、持続的なプレッシャー下で通用する戦術、そして面白くなる前にランを終わらせるミスを分解する。ここにある内容は、ウェーブベースの呪い生存モードが一般にどう振る舞うかに基づいて構成し、コミュニティ報告の観察は明確にラベル付けしている。

## タタリ・ホードモードとは実際何なのか

タタリ・ホードモードとは、ひとつの前提の上に築かれたウェーブベースの協力生存シナリオだ。長く持ちこたえるほど、環境そのものがあなたに不利に働く。固定の敵リストではなく、モードはプレッシャーを重ねていく — 敵の数、より厳しいスポーン間隔、より苛酷なモディファイア — そしてスクワッドが安定するか崩壊するまで続く。

この名前は飾りではない。日本の民間伝承では、*タタリ*とは、不当に扱われ、十分に鎮められなかった霊に起因する呪いや災いのことだ。これは、厄災を終わらせるために怨念を持つ死者をなだめる [御霊信仰](https://en.wikipedia.org/wiki/Gory%C5%8D) に密接に関連している。このテーマに基づくホードモードは通常、それをメカニクスに変換する。恨みが蓄積し、倒れた敵が残留物を残し、アリーナはあなたがしたことを覚えている。

| 属性 | 期待されること |
|---|---|
| 形式 | ウェーブベースの協力生存、小規模スクワッド |
| セッション長 | 開始時は短く、深く進むほど伸びる |
| 勝利条件 | 最終ウェーブを生き延びるか、脱出を完了する |
| 敗北条件 | いずれかの時点でスクワッド全員が戦闘不能 |
| 難易度曲線 | 緩やかな序盤、その後は急峻な中盤の上昇 |
| 特徴的なメカニクス | 蓄積する呪いのプレッシャー、または積み重なるモディファイア |
| 重視されるスキル | 生のダメージよりも位置取りとターゲット優先度 |

特徴的なメカニクスこそ、タタリ・ホードを一般的なゾンビウェーブモードと分けるものだ。プレッシャーはモードがあなたに対して使う資源であり、ウェーブをきれいに片付けたからといってリセットされるものではない。

## タタリ・ホードのランはどう構成されているか

ほぼすべてのバージョンのこのモードは、同じ感情の弧をたどる。自信、摩擦、パニック、そして制御か全滅かだ。自分がどの段階にいるのかを認識できれば、次に何をすべきかがわかる。

| 段階 | 起きていること | あなたの優先事項 |
|---|---|---|
| 序盤 | まばらなスポーン、寛容なテンポ | 資源を貯め、スポーン経路を学び、過度な前進を避ける |
| 激化 | 敵の種類が増え、側面が開く | 動き回るのではなく、強力な2地点を固定する |
| プレッシャー | モディファイアが重なり、雑魚と一緒にエリートが出現 | クールダウンを回し、火力役を守る |
| 消耗戦 | 息つく間もない継続スポーン | 消耗品を節約し、地面を保持し、キルを追うのをやめる |
| 終盤 | 最大密度＋ボスクラスの脅威 | すべてを燃やすが、逃げ道を1つ確保しておく |

コミュニティ報告は一貫して、激化とプレッシャーの間の移行こそ本当のフィルターだと指摘している。前半を順調に進んだスクワッドは、後半に入る時点で回復手段を使い果たし、アルティメットを空打ちし、後退位置もないことがよくある。このモードがあなたを直接殺すことはまれだ — あなたが答えを使うのが早すぎたから殺すのだ。

### プレッシャー曲線は敵の数より重要

よくある誤解は、タタリ・ホードは単に敵の数が増えるから難しくなるというものだ。実際には、難しさは*重なり*から来る。雑魚がまだ生きているのにエリートが到着し、遠距離の脅威が近接の脅威を援護し、前のウェーブで頼った戦術そのものを罰するモディファイアが来る。画面にいくつの敵がいるかだけでなく、モードが何を積み重ねているかを追跡しよう。

## 深いウェーブを生き残るチーム役割

ほとんどのビルドでソロプレイは可能だが、ほぼ完璧な資源管理を要求される。スクワッドでは、役割の明確さが、制御されたランと混乱の差になる。

| 役割 | 主な仕事 | よくあるミス |
|---|---|---|
| アンカー／前衛 | チョークポイントを保持し、アグロを吸い、経路を体で塞ぐ | ラインを越えてキルを追う |
| CC（群衆制御） | 敵集団を減速、スタン、束ね、よろめかせる | 単体ターゲットにCCを無駄遣いする |
| 単体火力 | エリートとボスクラスの敵を素早く排除する | エリートが自由に詠唱しているのに雑魚を撃つ |
| サポート／ユーティリティ | 回復、デバフ解除、蘇生、味方の位置調整 | 誰にも届かないほど後ろでプレイする |
| フレックス | 穴を埋め、ローテーションをカバーし、分断スポーンに対処 | すべての役割を同時にやろうとする |

### なぜ構成が個人技に勝るのか

CCを持たない強いプレイヤー4人のスクワッドは、平均的なプレイヤーによるバランスの取れたチームに負ける。このモードの脅威は加算的ではなく乗算的だ — スタンした集団は解決済みの集団であり、4人が別々にカイトしているのは4つの別々の緊急事態である。

## ラインを保持するための核心戦術

これらの原則は、モードがどんな特定の敵を投げてくるかに関係なく、ほとんどのタタリ・ホード構成で通用する。

- **開けた地面ではなく、地形から戦う。** チョーク、角、高所は、どんな単一のビルド選択よりも生存性に貢献する。
- **優先順位どおりに殺す。** 無効化、蘇生阻害、他者へのバフができるものは最初に死ぬ。雑魚は範囲ダメージのついでに死ぬ。
- **逃げ道を1つ確保する。** レーンが崩壊する瞬間のために、移動アビリティ、スモーク、または強力なCCを温存する。
- **ユニットとしてローテーションする。** 3つのスポーンをカバーするために分かれるスクワッドは、たいてい3つすべてを失う。
- **体力バーではなくモディファイアを追う。** 体力は回復できるが、悪いモディファイア相互作用はしばしば回復できない。
- **ウェーブ間でリセットする。** モードが休憩時間を与えるなら、回復、リロード、位置調整に使う — 略奪ではない。

| 脅威タイプ | 正しい対応 | 間違った対応 |
|---|---|---|
| 密集した雑魚の群れ | 範囲ダメージ＋チョークポイント | 各敵と個別に決闘する |
| 遠距離攻撃者 | 遮蔽物の後ろから距離を詰めるか、制圧する | 開けた場所で撃ち合う |
| エリート／装甲ユニット | 単体火力で集中砲火する | グループ全体にダメージを分散させる |
| 無効化役 | 可能なら遠距離から、行動する前に殺す | サポートに到達させる |
| ボスクラス | クールダウンを一度にすべてではなく、順番に回す | 最初の10秒で全部燃やす |

### 資源規律が長期ランを制する

消耗品はウェーブ予算として扱う。位置取りで片付けられたはずのウェーブに主要クールダウンを使うなら、そのウェーブに二重払いしたようなものだ。コミュニティの経験によれば、最も深く進むスクワッドはたいてい、前半が最も退屈なスクワッドだ — 英雄的行為も、パニックボタンもなく、ただクリーンなクリアがあるだけだ。

## タタリ・ホードのランを終わらせるよくあるミス

| ミス | なぜランを殺すのか | 修正 |
|---|---|---|
| 序盤の過度な前進 | 追加のスポーン集団を引き寄せ、スクワッドを分断する | ウェーブがほぼ片付くまで固定ラインを保持する |
| モディファイアの蓄積を無視する | モディファイアが複合し、ビルドを無効化する | 数ウェーブごとにアクティブなモディファイアを読み直す |
| クールダウンを溜め込む | 道具を使い切らないまま死ぬ | ダメージから回復するためではなく、ダメージを防ぐためにクールダウンを使う |
| 逃げる敵を追う | 陣形を崩し、背後にレーンを開ける | 逃げる敵は行かせて、代わりに位置を調整する |
| 蘇生を怠る | 1人の戦闘不能が連鎖全滅になる | 安全な蘇生を優先するが、1人を救うために2人を犠牲にしない |
| ウェーブ中の略奪欲 | わずかな利益のために悪い位置取りを強いる | 休憩中か完全クリア後のみ略奪する |

これらほぼすべての背後にあるパターンは同じだ。小さく即時の利益のために、大きく遅れて来るコストを支払っている。タタリ・ホードはその借金を取り立てるように設計されている。

## 報酬、進行、そしてさらに深く進むべき時

報酬構造は実装によって異なるが、ウェーブ生存モードは一般に、キル数ではなく深さと完了度に応じて支払いを拡大する。これには実用的な含意がある。1段階早く終わるクリーンなランは、たいてい2段階先まで足を引きずって進んで全滅する乱雑なランより優れている。

| ランの深さ | リスクレベル | 典型的な報酬プロファイル |
|---|---|---|
| 序盤〜中盤 | 低 | 安定した通貨、学習価値、低い時間コスト |
| 激化〜プレッシャー | 中 | ほとんどのプレイヤーにとって最良のリスク対報酬比 |
| 消耗戦以降 | 高 | プレミアム報酬、調整済みビルドと通話が必要 |
| 終盤／ボス | 非常に高 | 最上位の支払い、高い全滅確率 |

まだキャラクターを育成中なら、中程度の深さの帯を繰り返し周回するほうが、深いランに賭けるより通常は効率的だ。消耗戦を消耗品なしで生き延びられるようになったら、それが押し進める合図だ。

## タタリ・ホードに関するよくある質問

**タタリ・ホードモードはソロ向きですか？**
ソロでもプレイ可能ですが、ミスの許容範囲は劇的に狭まります。蘇生と分断スポーンをカバーする2人目がいない場合、自己回復、CC、機動力を持つビルドが必要です — つまり通常は最大ダメージを犠牲にすることになります。ほとんどのプレイヤーはデュオランが最適点だと感じています。

**典型的なタタリ・ホードのランはどのくらいかかりますか？**
セッション長は深さに比例します。浅いランはすぐに終わりますが、深い挑戦はかなり長くなることがあります。特に急ぐのではなく慎重に片付ける場合はそうです。終盤に挑む前に、長時間セッションになる可能性を想定しておきましょう。

**報酬はウェーブの深さに比例しますか？**
一般にははい — 支払いはキル数よりも深さと完了度に連動する傾向があります。だからこそ、きれいに終わる規律あるランは、紙の上ではより長く生き残る混沌としたランよりもしばしば優れています。

**新規プレイヤーがする最大のミスは何ですか？**
過度な前進です。序盤のほぼすべての全滅は、誰かがキルを追って確立したラインを離れ、それが追加スポーンを引き寄せ、陣形を崩壊させることに由来します。まずその癖を直せば、タタリ・ホードは劇的に扱いやすくなります。

基本を正しく押さえよう — 地形を保持し、優先順位どおりに殺し、問題を修正するためではなく予防するために資源を使う。そうすれば、このモードは混沌のように感じられなくなる。読めるリズムのように感じ始め、やがて制御できるものになる。
